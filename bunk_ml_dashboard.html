→ How ML Works Here
Generate 300 synthetic student records with varied attendance, thresholds & study habits.
Extract features: total_classes, attended, remaining, threshold, current_pct, study_hours, difficulty.
Linear Regression learns to predict the exact number of bunks using scaled features.
Logistic Regression classifies: is it safe to bunk at all? (binary: yes/no).
StandardScaler normalizes inputs so all features contribute fairly.
80/20 split — 240 rows train, 60 rows test. Evaluated on unseen data.
